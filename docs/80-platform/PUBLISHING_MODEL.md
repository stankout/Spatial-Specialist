# AC Spatial Specialist — Publishing Model

Status: CANONICAL PLATFORM SUMMARY

The public platform follows an explicit separation:

`Working Draft → Preview → Authorized Publish → Public renderer`

- Saving Draft does not change public output.
- Content requires `published` status and an explicitly published locale.
- Social public renderers read the Published collection, never Working Draft.
- Visual Director public rendering reads Published settings; development preview may read Draft only through the guarded preview path.
- Page Assets Draft assignments are preview-only. A public assignment still requires media eligibility.
- Page records distinguish draft/internal from published/public.

Publication is an authorized state transition. It is not implied by editing, assignment, upload, route existence, configuration, or preview.

Detailed sources: [Content Studio](../CONTENT_STUDIO.md), [Studio Administration](../STUDIO_ADMIN.md), [Visual Director](../VISUAL_DIRECTOR.md), [Media Library](../MEDIA_LIBRARY.md), and [Social Channels](../SOCIAL_CHANNELS.md).
