# AC Spatial Specialist — Media Direction

Status: DRAFT
Document Class: Media Design Specification
Intended Canonical Location: docs/30-design/MEDIA_DIRECTION.md

---

## 1. Media Purpose

Media should help AC:

- explain
- establish identity
- visualize property
- visualize space
- demonstrate ideas
- create atmosphere
- educate
- support decision-making

Media should not exist merely to fill empty layout.

---

## 2. Media Categories

Important media categories include:

- Owner Portrait
- Service Portrait
- Property Media
- Diagram
- Document
- Hero Image
- Hero Video
- Story Backdrop
- Ambient Video
- Procedural Scene
- Editorial Media
- Article Media
- Product Media
- Social Media
- Poster / Advertisement

---

## 3. Human / Portrait Direction

Portraits should communicate:

- trust
- personality
- competence
- identity

Avoid excessive visual effects covering the subject.

Transparent portraits may be integrated into cinematic environments.

---

## 4. Property Media

Property media should preserve informational value.

Avoid crop choices that remove important spatial/property context.

Media used to describe a specific property should not imply conditions that are not visible or verified.

---

## 5. Diagrams

Diagrams should prioritize completeness and legibility.

Default:

CONTAIN

Avoid arbitrary cropping.

---

## 6. Compass / Spatial Media

Compass and orientation assets should preserve:

- orientation
- complete graphic structure
- labels
- intended direction relationships

Default:

CONTAIN

---

## 7. Video Backgrounds

Background videos should normally be:

- muted
- looped where appropriate
- subtle
- text-safe
- optimized
- supported by poster fallback

Do not autoplay audible video.

---

## 8. Procedural Media

AC-native procedural scenes are preferred where an original technological environment is needed.

Examples:

- AC Ambient Intelligence
- Market Network
- Spatial Field
- Global Intelligence
- Cyber Archive
- Signal Terminal
- Astral Tech

Procedural visuals should remain original and configurable.

---

## 9. Production Quality

Do not claim a raster asset is "4K quality" solely because it was resized.

Prioritize:

- appropriate source quality
- vector/procedural resolution independence
- genuine high-resolution output
- optimized delivery

---

## 10. Mobile Media

Mobile may use:

- alternative crop
- alternative focal point
- lighter video
- poster fallback
- simplified procedural scene

Mobile should not automatically download expensive desktop decorative media.

---

## 11. Media Approval

Production media must pass applicable:

- source review
- rights review
- privacy review
- quality review
- metadata
- owner/role approval

Reference media should remain separate.
