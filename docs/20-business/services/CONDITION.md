- current laws/regulations
- professional qualifications
- training/certifications
- business structure
- brokerage/service-boundary issues
- insurance
- agreements
- scope of service
- standards of practice
- code of ethics
- reporting workflow
- client documentation
- pricing
- scheduling
- record retention
- public disclosures
- website presentation

The exact legal/regulatory requirements must be verified using current authoritative sources at the time activation is considered.

This document does not assert that any particular credential is legally required unless separately verified.
