# ODR-001 — Role is not Capability

Status: CURRENT POLICY
Domain: Operations
Effective date: Not asserted by K0

## Decision

An organizational Role describes responsibility and authority. A software Capability describes an allowed platform action. Software implements approved authority; it does not create company authority.

## Reason

The separation supports least authority, delegation, and future staffing without granting broad access merely from a title.

See [Roles and Authority](../../70-operations/ROLES_AND_AUTHORITY.md) and [Security and Access](../../80-platform/SECURITY_AND_ACCESS.md).
