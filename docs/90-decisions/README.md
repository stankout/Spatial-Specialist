# AC Spatial Specialist — Decision Records

Status: CANONICAL GOVERNANCE INDEX

Decision records explain durable policy and rationale. They do not replace the owning specification. K0 records use `CURRENT POLICY` when the repository verifies the rule but does not provide enough evidence to invent an approval date or historical attribution.

See the cross-domain [Decision Index](../00-core/DECISION_INDEX.md). Unresolved choices remain in the non-canonical [Owner Decision Register](../95-workbench/owner-decisions/OWNER_DECISION_REGISTER.md).
