- composition
- visual language
- motion
- advertising

- creative techniques

## 6. Copyright and Production Boundary

AC should not assume that publicly viewable material may be copied into production.

Reference analysis may extract concepts such as:

- grid density
- rhythm
- composition
- lighting
- contrast
- motion speed
- hierarchy
- interaction pattern

Avoid copying:

- protected artwork
- logos
- proprietary interface identity
- watermarks
- exact branded compositions
- copyrighted footage without permission

---

## 7. AI Use

AI tools may receive approved reference material for design analysis where appropriate.

The prompt should clearly distinguish:

WHAT TO LEARN

from:

WHAT NOT TO COPY.

Output intended for production should be original or appropriately licensed/approved.

---

## 8. Large Media

Large raw footage, high-resolution reference video and temporary creative files should not be committed to Git by default.

The repository may store:

- metadata
- thumbnails where appropriate
- manifests
- paths
- descriptions

while raw assets remain in approved external/local storage.

---

## 9. Production Promotion

A Reference may become a Production Asset only when:

- rights are known
- usage is permitted
- privacy is acceptable
- quality is sufficient
- owner approval exists
- appropriate Media workflow is completed

Reference folders themselves should never be treated as production asset sources automatically.
